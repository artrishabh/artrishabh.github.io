Shader Graph Named Reroute

A Unreal Engine like named reroute custom node for Unity Shader Graph.

2026-08-24
Unity ToolsShader Graph

Overview

I really liked the Named Reroute feature in Unreal Engine's material graph and was surprised Unity Shader Graph didnt have a direct equivalent. So I built a small editor utility that adds two custom nodes: Declare Reroute and Use Reroute. You can name a value once and access it elsewhere in the graph without dragging long wires across everything

The problem

Large Shader Graphs can quickly become difficult to read when values need to be reused across different parts of the graph, especially when long connection wires cross multiple node groups. The Named Reroute tool solves this by letting you declare a value with a name and reuse it elsewhere through a matching Usage node. This keeps the graph cleaner and makes important values easier to identify at a glance. It’s especially useful for commonly reused data such as masks, normals, UVs, depth values, Fresnel results, or any intermediate calculation that needs to be referenced in multiple places.

How I built it

I created the tool as a small Unity Editor extension for Shader Graph, adding two custom nodes: Declare Reroute and Use Reroute. The Declaration node stores a name and accepts a Shader Graph value, while Usage nodes with the same name are linked back to it internally. The tool keeps the actual graph dependency intact but hides the long connection between them. Most of the work involved interacting with Shader Graph’s node/slot system, handling dynamic value types, keeping names synchronized, and working around some of Unity’s internal Shader Graph APIs.

Usage

  1. In Shader Graph, open Create Node → ArtRishabh → Named Reroute.
  2. Add a Declaration node and connect the value you want to reuse.
  3. Give the Declaration a name, for example FoamMask.
  4. Add a Usage node somewhere else in the graph.
  5. Select/type the same reroute name.
  6. Connect the Usage output wherever that value is needed.
  7. One Declaration can be reused by multiple Usage nodes, which helps keep large graphs much cleaner.
