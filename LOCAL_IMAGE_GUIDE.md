# Adding game screenshots

The game catalogue and project pages now use local files only. External itch.io screenshots are no longer required.

For Divine Darkness, add:

```text
assets/games/divine-darkness/shot-1.png
assets/games/divine-darkness/shot-2.png
assets/games/divine-darkness/shot-3.png
```

These files automatically appear in the Divine Darkness gallery. `shot-1.png` also becomes the catalogue image unless you add `cover.png`.

Optional files:

```text
assets/games/divine-darkness/cover.png
assets/games/divine-darkness/hero.png
```

The same naming system works for every game. See `assets/games/README.md` for the complete list of folder names and supported formats.
